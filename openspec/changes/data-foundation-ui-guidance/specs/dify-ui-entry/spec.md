# Spec Delta

## Purpose

定义若依前端中 Dify 研究能力的受控交互入口：用户在研究任务、材料/新闻、标的详情和全局研究助手中触发 AI 辅助，但浏览器始终只调用 Spring Boot，AI 输出以草稿和解释呈现，不能绕过核验、审核、策略或 Paper 门禁。

## ADDED Requirements

### Requirement: Dify 触发入口统一走 Spring Boot
前端 SHALL 在研究任务页、材料/新闻详情页、标的/行情详情页和全局研究助手提供受权限控制的 Dify 操作入口；浏览器不得持有或调用 Dify API Key，所有调用先提交 Spring Boot 研究任务或问答 API。

#### Scenario: 用户从新闻详情触发事实提取
- **WHEN** 用户在授权新闻详情点击“提取事实/分析影响”
- **THEN** 前端创建研究任务并显示任务 ID、输入快照和处理状态，浏览器不直接请求 Dify

#### Scenario: 用户无研究权限
- **WHEN** 用户没有研究任务创建权限
- **THEN** 页面隐藏或禁用 Dify 触发入口并给出权限说明，不能通过手工 URL 触发

### Requirement: Dify 研究任务状态可视化
前端 SHALL 显示研究任务准备、排队、Dify 运行、流式接收、校验、待审核、完成、失败、超时和降级状态；状态刷新优先通过 REST 轮询，二期可扩展 SSE/WebSocket，但不得改变业务状态主控。

#### Scenario: Dify 正在运行
- **WHEN** 用户提交研究任务且 Dify 正在流式处理
- **THEN** 页面显示“正在分析”、已保存的输入版本和可安全离开/稍后回来选项，不把中间文本显示为最终事实

#### Scenario: Dify 超时
- **WHEN** 任务超过配置的超时时间
- **THEN** 页面显示超时原因、是否可重试和结构化数据仍可查看；重试沿用任务幂等关系，不重复创建研究事实

### Requirement: AI 草稿与核验事实分层展示
前端 SHALL 清晰区分 AI 草稿、系统计算、待核验事实、已核验研究事件和未知信息；每个结论可展开到来源、原文/字段片段、发布时间、可见时间、快照和版本。

#### Scenario: 草稿引用待核验
- **WHEN** AI 草稿引用缺失或未通过引用校验
- **THEN** 页面标注“AI 草稿/引用待核验”，提供补证据/交审核操作，不显示“已确认事实”标签

#### Scenario: 研究事件已发布
- **WHEN** Spring Boot 完成校验并发布研究事件
- **THEN** 页面显示已核验状态、证据链、版本和影响范围，并提示后续仍需策略适配，不提供直接下单操作

### Requirement: 受控研究问答入口
全局研究助手 SHALL 允许用户用自然语言询问数据是否可用、材料发生了什么、日历/行情为何阻断和研究下一步；Spring Boot 先执行权限范围内结构化查询，再将最小结果交给 Dify 组织语言，回答必须带时间、来源、状态和不确定性。

#### Scenario: 查询日线是否可用
- **WHEN** 用户在研究助手询问“今天能不能研究/有没有模拟机会”
- **THEN** Spring Boot 返回授权范围内的数据日期、日历、质量和资格结果，Dify只组织解释；若不满足，回答原因和下一步，不虚构机会

#### Scenario: 问答包含操作意图
- **WHEN** 用户在问答中说“开始分析这个标的”或“加入关注”
- **THEN** Dify只返回受控意图草稿，前端转换为明确的确认表单/任务命令，Spring Boot重新执行权限、版本和门禁校验

### Requirement: Dify 降级与安全提示
前端 SHALL 在 Dify 不可用、限流、授权失败或输出无效时显示降级状态，同时保留确定性数据、日历、行情和已有研究结果入口；不得展示密钥、内部 URL、完整 Prompt、原始敏感响应或将 AI 错误隐藏为“暂无数据”。

#### Scenario: Dify 服务不可用
- **WHEN** Spring Boot 返回 Dify 降级状态
- **THEN** 页面显示“AI研究暂不可用/可稍后重试”，提供结构化数据查询和已有结果入口，研究任务不显示为成功

### Requirement: UI 禁止绕过 Dify 与交易边界
前端 SHALL 不提供 Dify 草稿直写事实、候选直达策略信号、研究结果直达 Paper 订单、AI 一键平仓/开仓或真实交易入口；页面必须显示模拟资金/真实交易隔离提示。

#### Scenario: 用户查看研究结果
- **WHEN** 用户在 AI 研究结果页查看方向候选或重大程度候选
- **THEN** 页面只显示研究草稿/核验状态和下一步研究入口，不显示可直接执行的交易命令
